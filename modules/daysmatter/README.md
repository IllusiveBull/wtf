# Days Matter Widget

一个用于追踪重要日期和纪念日的WTF插件。

## 功能特点

- 📅 显示距离重要日期还有多少天或已过去多少天
- 🔄 支持每年重复的纪念日（如生日、结婚纪念日等）
- 🎨 根据时间紧迫程度自动着色
- ⏰ 自动排序（即将到来的事件优先显示）

## 配置示例

在你的 `~/.config/wtf/config.yml` 中添加：

```yaml
daysmatter:
  enabled: true
  position:
    top: 0
    left: 0
    height: 2
    width: 1
  refreshInterval: 1h
  events:
    - name: "生日"
      date: "1990-05-15"
      yearly: true
    - name: "结婚纪念日"
      date: "2020-10-01" 
      yearly: true
    - name: "项目截止日期"
      date: "2024-12-31"
      yearly: false
```

## 配置参数

### 基本配置
- `enabled`: 是否启用插件
- `position`: 插件在界面中的位置
- `refreshInterval`: 刷新间隔（建议1小时或更长）

### 事件配置
每个事件包含以下字段：
- `name`: 事件名称（字符串）
- `date`: 目标日期，格式为 "YYYY-MM-DD"
- `yearly`: 是否每年重复（布尔值）

## 显示逻辑

### 颜色编码
- 🔴 **红色**: 今天或7天内的事件
- 🟡 **黄色**: 8-30天内的事件  
- 🟢 **绿色**: 30天以上的未来事件
- ⚫ **灰色**: 已过去的事件

### 文本格式
- 未来事件: `事件名称 - 还有 X 天`
- 今天的事件: `事件名称 - 今天！`
- 过去事件: `事件名称 - 过去了 X 天`

### 排序规则
1. 未来事件按时间远近排序（越近越靠前）
2. 过去事件按时间远近排序（越近越靠前）
3. 未来事件始终显示在过去事件之前

## 年度重复事件

对于设置了 `yearly: true` 的事件：
- 如果今年的日期还未到达，显示距今年日期的天数
- 如果今年的日期已过，显示距明年日期的天数
- 对于已过去的年度事件，显示距今年该日期过去的天数
